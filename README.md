# DAA Assignment 3 — Graph Algorithms
An educational Java project implementing, testing, and comparing graph algorithms.
## Features
- DSU: path compression and union by size.
- Kruskal and Prim: minimum spanning forests.
- Kosaraju and Tarjan: strongly connected components.
- Kahn: topological sorting; DagShortestPath: shortest paths in a DAG.
- Graph condensation and critical path computation.
- Metrics: execution time, DSU operations, edge scans, comparisons, and stack depth.
